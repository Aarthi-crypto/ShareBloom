ShareBloom

A society-oriented mobile application that connects people in need with donors who want to contribute unused resources, bridging community gaps through technology.

Features
- Post resource requirements
- Donors can browse and respond to requests
- Simple, user-friendly interface
- Encourages reuse of unused items for social good

Tech Stack
- Java
- Android Studio

How to Run
1. Clone the repository
2. Open it in Android Studio
3. Let Gradle sync finish
4. Run on an emulator or Android device
